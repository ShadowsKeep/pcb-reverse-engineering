# Contributing

Feedback from real boards is the most useful thing you can give.

- **It worked, or it didn't, on your board:** open an issue with the "How it worked on my board" form. Bad results are just as welcome as good ones.
- **A script failed or gave a wrong answer:** open an issue with the "Something went wrong" form, and paste the last lines it printed.
- **A question, or a board you want to show:** start a [discussion](https://github.com/ShadowsKeep/pcb-reverse-engineering/discussions).
- **Code:** pull requests are welcome. Keep the scripts to the Python standard library plus Pillow and numpy, and say which board you tested on.

Please only share photos of boards you are allowed to share.
